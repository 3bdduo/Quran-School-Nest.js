# Quran School API — NestJS Architecture

مشروع إعادة بناء للخدمة الخلفية (Backend) الخاصة بنظام إدارة دار القرآن الكريم باستخدام **NestJS** و**TypeScript** اعتمادًا على قاعدة بيانات MongoDB عبر مكتبة Mongoose، مع الحفاظ على المسارات والتكامل الكامل مع الواجهة الأمامية الحالية عبر البادئة `/api/v1`.

---

## 1. التحديثات والتعديلات الهيكلية

### إعادة الهيكلة والتأمين
* التحول من بنية Express التقليدية إلى بنية модуلية متكاملة (Modules, Controllers, Services, Guards, Interceptors).
* استبدال آليات التحقق اليدوية باستعمال `JwtAuthGuard` و`RolesGuard` بالاعتماد على مكتبة `passport-jwt`.

### معالجة آلية العمل في وحدة المسابقات (Competitions)
* منع تسجيل نتائج للطلاب غير المسجلين كأعضاء مشاركين في المسابقة.
* احتساب ترتيب المراكز (`rank`) تلقائيًا بناءً على الدرجات تنازليًا في حال عدم تحديده.
* حذف نتائج المشارك تلقائيًا عند إزالته من قائمة المسابقة للحفاظ على اتساق البيانات.
* إرسال إشعارات فورية لكل المشاركين مع تنبيهات خاصة للمراكز الثلاثة الأولى عند إعلان النتائج.

### تصحيح وتحسين وحدة الإشعارات (Notifications)
* إضافة شرط الاستعلام الخاص بـ `eduGroupId` ضمن مسارات `/me` و `/unread-count` لضمان وصول الإشعارات لمعلمي المجموعات التعليمية.
* إمكانية الاستهداف المباشر على مستوى طالب معين (`student:<id>`) أو معلم محدد (`teacher:<username>`).

### الأتمتة المدمجة (Automated Triggers)
* **سجل النشاطات (Activity Log):** تتبع وتسجيل عمليات الإضافة والتعديل والحذف الناجحة تلقائيًا عبر Interceptor عام.
* **إشعارات العمليات:** توليد إشعارات تلقائية عند تسديد الاشتراكات، رصد الامتحانات، صرف الرواتب، وتحديث مستويات التسميع.
* **متابعة الغياب:** إرسال تنبيه آلي للحلقة عند تسديد 3 حالات غياب متتالية للطالب.

### وحدة التصدير واستخراج التقارير (Exports Module)
إضافة مسارات مخصصة لتصدير التقارير بصيغ Word (`.docx`) و Excel (`.xlsx`) بتنسيق عربي (RTL) لدعم الإدارة، مقتصرة على صلاحية الأدمن (`admin`):

| المسار | الصيغة | الوصف |
|---|---|---|
| `GET /api/v1/exports/students.xlsx` | Excel | كشف بيانات الطلاب |
| `GET /api/v1/exports/students/:id.docx` | Word | تقرير تفصيلي شامل للطالب |
| `GET /api/v1/exports/payments/:monthKey.xlsx` | Excel | تقرير المدفوعات الشهرية |
| `GET /api/v1/exports/attendance/:groupId.xlsx?date=YYYY-MM-DD` | Excel | كشف الحضور اليومي للمجموعة |
| `GET /api/v1/exports/salaries/:monthKey.xlsx` | Excel | مسيرات رواتب المعلمين |
| `GET /api/v1/exports/competitions/:id.docx` | Word | نتائج المسابقات الرسمية |
| `GET /api/v1/exports/dashboard.docx?monthKey=YYYY-MM` | Word | التقرير التنفيذي العام |
