# 🕌 Quran School API — نسخة NestJS

نسخة كاملة معاد بناؤها بـ **NestJS + TypeScript** من مشروع الـ Express الأصلي، بنفس الداتابيز (MongoDB/Mongoose)
ونفس الـ endpoints تقريبًا (base path: `/api/v1`)، مع إصلاحات وأتمتة إضافية وميزة تصدير تقارير Word/Excel جديدة.

---

## 🆕 أهم الفروقات عن النسخة القديمة

### 1) البنية
- من Express Router عادي → NestJS Modules/Controllers/Services/Guards/Interceptors (بنية احترافية قابلة للتوسع).
- `authenticate` + `authorize` القديمين → `JwtAuthGuard` + `RolesGuard` + `@Roles()`.
- التحقق من صحة التوكن بقى عن طريق `passport-jwt` بدل `jwt.verify` اليدوي.

### 2) إصلاحات حقيقية في المسابقات (Competitions)
- **قبل:** ممكن تتحفظ نتيجة لطالب مش مسجل أصلاً كمشارك في المسابقة.
  **بعد:** أي نتيجة لطالب مش مشارك بترفض برسالة واضحة.
- **قبل:** الترتيب (`rank`) لازم يتبعت يدوي من الفرونت إند وممكن يتغلط فيه.
  **بعد:** لو مبعتش ترتيب، بيتحسب أوتوماتيك من ترتيب الدرجات تنازليًا.
- **جديد:** بعد حفظ النتائج، بيتبعت إشعار أوتوماتيك لكل مشارك (وتنويه خاص 🏆 لأصحاب المراكز التلاتة الأولى).
- **جديد:** حذف مشارك من المسابقة بيمسح نتيجته المرتبطة تلقائيًا عشان البيانات تفضل متسقة.

### 3) إصلاحات في الإشعارات (Notifications)
- **باگ اتصلح:** النسخة القديمة كانت مش بتحط شرط `eduGroupId` في استعلامات `/me` و `/unread-count`،
  فالمدرس اللي بيدرّس مجموعة تعليمية بس (من غير حلقة تحفيظ عادية) كان ممكن يفوّت إشعارات موجهة لمجموعته.
  اتصلح دلوقتي.
- **جديد:** استهداف أدق — إشعار لطالب بعينه (`student:<id>`) أو لمدرس بعينه (`teacher:<username>`)
  بالإضافة للاستهداف العام (`all` / `teachers` / رقم الحلقة).

### 4) أتمتة جديدة (كانت بتتعمل يدوي أو مش موجودة خالص)
| الحدث | كان قبل كده | بقى دلوقتي |
|---|---|---|
| سجل النشاطات (Activity Log) | لازم الفرونت إند يبعت طلب منفصل بعد كل عملية | **بيتسجل أوتوماتيك** لأي عملية إضافة/تعديل/حذف ناجحة، عن طريق Interceptor عام |
| تسجيل طالب جديد | من غير أي تنبيه | إشعار أوتوماتيك لحلقة الطالب |
| تسجيل دفع اشتراك "مدفوع" | من غير أي تنبيه | إشعار "إيصال" أوتوماتيك للطالب |
| رصد امتحان جديد | من غير أي تنبيه | كل طالب ياخد إشعار بدرجته أوتوماتيك |
| نشر نتائج مسابقة | من غير أي تنبيه للمشاركين | إشعار عام لكل المشاركين + تهنئة خاصة للفايزين |
| صرف راتب معلم | من غير أي تنبيه | إشعار أوتوماتيك للمعلم |
| تسجيل تسميع/حفظ جديد | من غير أي تنبيه | إشعار أوتوماتيك للطالب بتحديث حفظه |
| غياب متكرر (3 مرات متتالية) | مفيش أي متابعة | **جديد بالكامل:** تنبيه أوتوماتيك لحلقة الطالب |
| إنشاء حلقة/مجموعة تعليمية جديدة | من غير أي تنبيه | إشعار ترحيبي أوتوماتيك للمدرس |

### 5) ميزة جديدة بالكامل: تصدير تقارير Word / Excel احترافية (للأدمن فقط)
كل التقارير دي بتنزل جاهزة للطباعة (اتجاه عربي RTL، هيدر باسم المدرسة، ألوان، جداول منسقة):

| Endpoint | النوع | الوصف |
|---|---|---|
| `GET /api/v1/exports/students.xlsx` | Excel | كشف كامل بكل الطلاب |
| `GET /api/v1/exports/students/:id.docx` | Word | تقرير شامل لطالب واحد (حضور، حفظ، مدفوعات) |
| `GET /api/v1/exports/payments/:monthKey.xlsx` | Excel | تقرير المدفوعات لشهر معين |
| `GET /api/v1/exports/attendance/:groupId.xlsx?date=YYYY-MM-DD` | Excel | كشف حضور يومي لحلقة |
| `GET /api/v1/exports/salaries/:monthKey.xlsx` | Excel | تقرير رواتب المعلمين (بديل احترافي لتصدير الـ CSV القديم) |
| `GET /api/v1/exports/competitions/:id.docx` | Word | نتائج مسابقة بشكل رسمي |
| `GET /api/v1/exports/dashboard.docx?monthKey=YYYY-MM` | Word | تقرير عام لأداء المدرسة |

كل المسارات دي محمية بـ `@Roles('admin')` — الأدمن الكبير بس اللي يقدر يستخدمها.

## ⚙️ التشغيل محليًا

```bash
npm install
cp .env.example .env   # عدّل القيم حسب بيئتك
npm run start:dev
```

السيرفر هيشتغل على `http://localhost:3000/api/v1` (أو البورت اللي في `.env`).
أول ما يشتغل، هيعمل تلقائيًا Seed لإعدادات افتراضية (اسم دخول الأدمن: `Admin`، والباسورد من `ADMIN_DEFAULT_PASSWORD`).

## 🚀 النشر على Railway

المشروع فيه `railway.toml` جاهز. الأوامر:
```bash
npm run build
npm run start:prod
```
لازم تظبط متغيرات البيئة دي في Railway: `MONGODB_URI`, `JWT_SECRET`, `JWT_EXPIRES_IN`, `ADMIN_DEFAULT_PASSWORD`, `CORS_ORIGINS`.

## 📁 بنية المشروع

```
src/
  main.ts                 نقطة تشغيل السيرفر
  app.module.ts            الموديول الرئيسي اللي بيجمع كل حاجة
  config/                  إعدادات البيئة
  schemas/                 كل Mongoose Schemas (18 موديل)
  common/
    guards/                JwtAuthGuard + RolesGuard
    decorators/             @Roles / @CurrentUser / @LogAction / @Public
    filters/                فيلتر موحّد للأخطاء
  modules/
    auth/                   تسجيل الدخول (JWT)
    settings/               إعدادات المدرسة
    groups/ edu-groups/     الحلقات والمجموعات التعليمية
    students/               الطلاب
    attendance/ edu-attendance/   الحضور
    memorization/           التسميع والحفظ
    payments/               الاشتراكات الشهرية
    exams/                  الامتحانات
    competitions/           المسابقات (فيها الإصلاحات المذكورة فوق)
    notifications/          الإشعارات (فيها إصلاح الباگ + الاستهداف الدقيق)
    activity-log/           سجل النشاطات + الـ Interceptor الأوتوماتيكي
    salaries/                رواتب المعلمين
    reports/                 لوحة التحكم والتقارير النصية (JSON)
    exports/                 ⭐ تصدير Word/Excel الاحترافي (ميزة جديدة)
    health/                  فحص حالة السيرفر (/health بره البادئة زي الأصل)
  seed/                     إنشاء الإعدادات الافتراضية تلقائيًا عند أول تشغيل
```

## 🔑 الفرق في الـ endpoints عن النسخة القديمة

كل الـ endpoints القديمة اتحافظ عليها **بنفس الأسماء وبنفس شكل الـ body/response** —
الفرونت إند الحالي المفروض يشتغل من غير أي تعديل. الإضافات فقط:
- `/api/v1/exports/*` (تصدير Word/Excel — جديد).
- حقل `resultsPublished` و `read_by_count`/`isRead` زي ما كانوا، بالإضافة لحقل `auto_generated` في الإشعارات (اختياري، مش هيأثر على الفرونت إند الحالي).
